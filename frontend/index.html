Scribble — Multi-Model AI Chat

Scribble is a free, independently run AI playground. Chat with, compare, and battle 60+ third-party AI models side by side in one interface — no sign-up required.

  • Direct — one-on-one chat with a model of your choice.
  • Battle — two anonymous models answer the same prompt; you vote.
  • Side by Side — compare two named models on one prompt.
  • Agent — a chat mode built for tool-using workflows.
  • Image — generate images from a text prompt.
