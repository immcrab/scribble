The short version

What is Lofin?

Lofin.dev is a web application where people can work with multiple AI models in one calm, focused interface. It is designed for exploring a question from different angles instead of treating one answer as the final word.

The product is independently run. It is not presented as a substitute for professional advice, a source of guaranteed-correct information, or an official service of any model provider.

Architecture

One interface, several model providers

Lofin connects its interface to a server-side Cloudflare Worker. The Worker passes requests to supported third-party AI and search providers, including xKiro, Mistral, Google Gemini, OpenRouter, Z.ai / GLM, Groq, Exa, and Cloudflare services where applicable.

That design keeps provider API keys out of a visitor’s browser. Models, plans, and availability change over time; the in-product model selector and documentation are the best places for the current catalog.

Data and control

Privacy, in plain language

By default, chat history and preferences stay in the browser’s local storage. Signing in can enable cross-device syncing and access to additional functionality. Some requests are sent to the selected model or tool provider so it can produce a response.

Features that use search, memory, file uploads, image generation, or sharing have their own data implications. Please read the Privacy Policy before using Lofin for sensitive work, and avoid putting confidential or personal information into any AI service unless you understand the relevant provider’s terms.

A note on AI

Use good judgment

AI-generated output can be incomplete, biased, outdated, or wrong. Review important answers, check primary sources, and consult qualified professionals for decisions involving health, law, finance, safety, or other high-stakes matters.
