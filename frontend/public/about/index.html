Scribble

About Scribble

Scribble is a small, independently run AI playground — a place to chat with, compare, and battle several third-party AI models side by side, in one interface, for free. It isn't a company or a funded product; it's a hobby project built and maintained by one person.

What it does

  • Direct — a normal one-on-one chat with a model of your choice.
  • Battle — two anonymous models answer the same prompt; you vote on the better response.
  • Side by Side — compare two named models on the same prompt at once.
  • Agent — a chat mode built for tool-using workflows.
  • Image — generate images from a text prompt.

Under the hood, a Cloudflare Worker proxies requests to xKiro, Mistral, Google Gemini, OpenRouter, and Cloudflare Workers AI, so provider API keys never touch your browser. Everything you type stays in your browser's local storage unless you sign in, which enables cross-device sync and unlocks the rest of the models and modes — see the Privacy Policy for the full picture.

Who's behind it
