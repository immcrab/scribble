Lofin.Dev — Multi-Model AI Chat

Lofin is a free, independently run AI playground. Chat with, compare, and battle 80+ third-party AI models side by side in one interface. Start instantly with no sign-up; sign in free to unlock every mode.

  • Direct — one-on-one chat with a model of your choice.
  • Battle — two anonymous models answer the same prompt; you vote.
  • Side by Side — compare two named models on one prompt.
  • Agent — a chat mode built for tool-using workflows, with an optional live web search.
  • Image — generate images from a text prompt, or edit one you upload.
  • Text to Speech — turn text into spoken audio.
